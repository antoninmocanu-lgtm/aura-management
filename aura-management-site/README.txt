AURA MANAGEMENT — SITE WEB

Contenu :
- index.html : page principale
- styles.css : design responsive (ordinateur, tablette, mobile)
- script.js : menu mobile et formulaire de contact par e-mail
- mentions-legales.html : modèle à compléter
- assets/aura-logo.jpg : logo extrait de l'image fournie

APERÇU LOCAL
Ouvrez index.html dans un navigateur. Une connexion internet est nécessaire pour charger les polices Google Fonts et la photographie de fond Unsplash. Le site reste lisible sans ces ressources.

MISE EN LIGNE GRATUITE AVEC GITHUB PAGES
1. Créez un compte gratuit sur https://github.com/ si vous n'en avez pas.
2. Créez un dépôt public nommé aura-management (ou aura-management.github.io).
3. Importez tous les fichiers et le dossier assets en conservant leur organisation.
4. Dans Settings > Pages, choisissez Deploy from a branch, puis la branche main et le dossier /(root).
5. Enregistrez. GitHub publiera le site sur une adresse gratuite github.io.

AVANT PUBLICATION
- Remplacez les coordonnées absentes et complétez mentions-legales.html.
- Ajoutez l'adresse e-mail professionnelle dans le formulaire : dans script.js, remplacez mailto:? par mailto:votre-adresse@domaine.fr? dans la ligne window.location.href.
- Vérifiez que les services présentés correspondent exactement aux prestations réellement proposées.
- Si vous souhaitez un formulaire qui enregistre directement les demandes sans ouvrir l'application e-mail, il faudra le connecter à un service de formulaire gratuit et consulter sa politique de confidentialité.

Le site ne prétend pas afficher de références clients, chiffres ou certifications non fournis.
